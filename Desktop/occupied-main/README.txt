Life Audit App
===============

How to use
----------
1. Extract LifeAuditApp.zip to a folder.
2. Open the dist folder.
3. Double-click myapp.exe to run the app.

Important
---------
- The app stores its data in %APPDATA%\LifeAuditApp\life_audit.db.
- The executable is standalone and does not require a separate Python install.

Share
-----
Send the LifeAuditApp.zip file to others, or upload it to a service like Google Drive, Dropbox, or OneDrive.

If you want, I can also create a simple installer with a desktop shortcut and install path for a nicer install experience.
